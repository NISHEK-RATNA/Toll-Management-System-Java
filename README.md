Toll Management System

A simple Java console-based application for managing vehicles at a toll gate and calculating toll charges based on vehicle type.

Features

- Add vehicle details
- Calculate toll based on vehicle type
- View all registered vehicles
- View total toll collection
- Display vehicle type summary
- Handle invalid vehicle types

Java Concepts Used

- Object-Oriented Programming (OOP)
- Abstraction
- Encapsulation
- Inheritance
- Polymorphism
- Switch and Conditional Statements
- Loops and Nested Loops
- Strings and Arrays
- Exception Handling
- ArrayList
- HashSet
- HashMap

How to Run

Compile the program:

javac TollManagementSystem.java

Run the program:

java TollManagementSystem
